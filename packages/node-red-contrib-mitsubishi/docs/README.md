## 🔑 重要な設計判断（要約）

| 判断 | 根拠 |
|------|------|
| **ゼロ依存** | 本番サプライチェーンリスク排除。MCプロトコルは安定仕様 |
| **読取・書込プール分離** | 散発的な書込が周期読取をブロックしない |
| **接続キーにframe/network/stationを含める** | 同一PLCへの3E/4E混在設定でパラメータ競合防止 |
| **書込グループは厳密隣接のみ** | ギャップをゼロ書込＝PLCデータ破壊を絶対防止 |
| **24種類のエラーコード** | プロトコルエラーを具体的に識別（デバッグ効率） |
