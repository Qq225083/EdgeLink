### 日本人レビュアーが特に確認すべき箇所

| 行番号 | 項目 | 確認ポイント |

| **55-58** | `poolKey` | 接続キー: `host:port:frame:networkNo:stationNo:protocol`。**frame/network/station を含めることで、同一 PLC への異なる設定（3E/4E 混在など）が接続を取り違えない。** |

| **466-489** | 計算タグ | 参照タグの `rawValue` を使用して add/sub/mul/div を実行。**ゼロ除算ガード（divisor=0 の場合は null）、欠損参照ガード（warn）。** |
