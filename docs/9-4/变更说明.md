## 六、追加变更（09-19 第二批）：edge_collector 账号种子（修复 bootstrap 登录 601）

### 问题
bootstrap 下发 `edge_collector` 账号给采集节点登录（`bootstrap_controller.py:150`），但该账号从未在任何迁移/init 脚本中创建，导致 V13 首次启动登录报 `601 用户不存在` 无限重试。属部署缺口（设计文档 edgelink_bootstrap_secure_design.md 5.2/5.3 规划了但未落地）。

### 改动
- `init_plc_db.py` 新增 8.5 节（幂等）：创建角色「采集节点/edge_collector」→ 授 `plc:tag:list`（快照拉取沿用点位读取权限；Monitor 接口走 X-API-Key）→ 创建/同步账号 `edge_collector`（bcrypt，密码取环境变量 `EDGE_COLLECTOR_PASSWORD`，须与后端 .env 的 `edge_collector_password` 一致；重复执行同步密码）→ 绑定账号↔角色。
- 运行方式：`set MYSQL_PASSWORD=... && set EDGE_COLLECTOR_PASSWORD=... && .venv/Scripts/python.exe init_plc_db.py`（Windows bash 用 `export`）。
- 验证：语法/ast 解析通过；bcrypt 可用。
- **执行实录（本机 09-19）**：角色 edge_collector 曾存在但软删除（del_flag='2'，7月建8月删）→ 复活；账号 edge_collector 新建（user_id=5）并绑角色；实测登录 ✓、权限 plc:tag:list ✓、`/plc/config/snapshot/list` 200 ✓（快照版本 46）、心跳 200 ✓（node_id=66）。补丁已兼容"角色被软删"场景（复活而非跳过）。
