# EdgeLink 契约变更附录（2026-07-27 整改轮 · Day 10 收口）

> 本附录汇总整改轮对系统契约的全部变更，供《系统详细设计说明书》后续章节修订时合并。
> 对应整改包：`docs/待整改7-27/`（问题清单/10天整改计划/验收总表）。

## 一、API 契约变更

### 1. 分页参数
- 全列表端点唯一生效参数为 camelCase `pageNum`/`pageSize`（FastAPI 按 alias 绑定）；snake_case（`page_num`/`page_size`）在多数端点静默失效退回默认值，仅 `/plc/tag/global/list` 手工兼容（供边缘）。调用方一律用 camelCase。
- 分页界：全部查询模型 `pageNum ge=1`、`pageSize ge=1 le=500`（tag global 例外 le=5000）。

### 2. 发布接口（POST /plc/config/publish）
- 响应 `data` 新增：`status`（success/partial/failed）、`failedDevices[]`（未送达明细）。失败如实返回，不再永远"成功"。
- `plc_publish_log` 新增列：`status`、`fail_detail`、`config_snapshot`（发布时配置快照，审计/回滚依据）。
- driver_code=UNKNOWN 的设备不再下发（记入 fail_detail）。

### 3. 心跳接口（POST /monitor/heartbeat）
- 响应 `data` 新增：`node_id`（原有）、`disabled`（kill switch 轮询兜底标志，边缘每周期比对）。
- 入参校验加强：`running_flows`/`memory_usage_mb`/`pg_*` 均 ge=0；`node_ip` 限长 20。
- 节点注册并发安全（savepoint），并发首报不再 500。

### 4. 密钥管理（/plc/bootstrap-key）
- `secret_key` 只存 SHA-256 哈希；列表/详情接口不再返回 secretKey；明文仅在新增/重置响应中返回一次。
- 新增注册窗口（按压配对）：`POST/GET/DELETE /plc/bootstrap-key/registration-window`——窗口开启时（默认 10 分钟 TTL）`/plc/config/bootstrap/auto` 才允许新节点注册；/auto 与 /bootstrap 各限流 20 次/分钟/IP。
- /auto 对已注册节点不再回吐 secretKey；fingerprint 命中不再改写 host_pc_ip。

### 5. 告警状态机
- `monitor_alert` 新增列：`last_notified_at`、`notification_pending`。
- 通知门控：仅 ①新建/重开 ②pending 补偿 ③超 30 分钟未通知的持续故障（severity 降级 3）才发 MQTT 通知。
- 重开=新 episode（重置通知态）；恢复覆盖 status 0/1；resolve_alert 对 node_id=0 且 device_id=0 的全量调用记警告。

## 二、边缘协议契约变更（Node-RED 侧）

### 1. 点位字段（协议节点 → data-processor）
- `rawValue` = **解码后的值**（32/64 位多字组装结果）；原始首字在 `rawWord` 备查。MC/Modbus 两侧一致。
- 质量码全链 OPC UA 语义：协议节点数字 0/1/2 → data-processor 字符串 GOOD/BAD/UNCERTAIN；lastGood 的 stale 标记用字符串 'UNCERTAIN'。
- `slope=0` 全链合法（不再被 `||1` 吞掉）；工程值当前统一 toFixed(2)（设计声明，后续评估可配置化）。

### 2. 死区
- `report_deadband_ms` 语义为**数值死区（工程单位）**，FLOAT 类型，默认 0；列名中的 `_ms` 为历史遗留（改名成本高于收益，以注释为准）。前端表单"变化死区（数值）"step=0.1。

### 3. 地址约定
- 全部为**协议 0 基地址**（Modbus 不支持 40001 风格）；MC 按软元件进制：W/B+非FX的X/Y=16 进制，FX 的 X/Y=8 进制，其余 10 进制。非法地址在保存层被拒。

### 4. kill switch（四通道）
- MQTT NODE_STATUS（实时，node_id 优先定向，空 host 丢弃）→ 心跳响应 disabled 标志（30s 轮询兜底）→ 重启 /bootstrap 停用文案 → 重启缓存 cache.disabled。

### 5. 驱动扩展
- driverCode 分流当前实际按 comType 回退（P1-2 未闭合，下一轮框架性改造）；新增协议当前需改 4 处代码（后端查询列、09 映射、13 分流分支、flow 连线）。

## 三、运维契约

- EMQX：内置 DB 认证 + 三账号 ACL（backend 仅发 notify / edge 订阅 notify+trigger 发 alarm,nodes,heartbeat / frontend 只读）+ no_match=deny；声明式备份 `docs/edgelink_emqx_config_backup.json`，恢复 `tools/restore_emqx_config.py`。
- PG：`edgelink.plc_data` 有唯一索引（幂等去重）+ 查询索引；spool 轮转 `.1` 会被重放，覆盖前有告警事件。
- 试运行观察：`tools/observe_trial.py`（每小时采样 KPI/PG 行数/spool 到 logs/trial_observe_*.csv）。
