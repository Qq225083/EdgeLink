## 2. 数据正确性（核心链路）

- [ ] FLOAT32/DOUBLE/INT32/UINT32 端到端：模拟器真值 vs PG `eng_value` 误差 <1e-4，quality=0，MQTT 同值。（P0-1）

- [ ] Q 系 X/Y 地址解析单测通过（X1A=26）；FX X/Y 八进制不回归（X17=15）。（P1-3）
- [ ] Modbus CR 点位发 FC01、DISCRETE 发 FC02（抓包/日志）。（P1-4）
- [ ] 死区语义统一：新建点位默认 0；0.5 死区点位变化 0.3 不上报、0.6 上报；存量 1000 已迁移。（P1-1）
- [ ] 非法地址（"abc"/"40001"/越界）在保存层被拒；不进入采集。（P1-19）
- [ ] 质量码 0/1/2 在 PG/告警/前端三处显示一致。（P1-20）
